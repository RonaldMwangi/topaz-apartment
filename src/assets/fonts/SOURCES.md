# Brand fonts

Downloaded from the official Google Fonts CSS endpoint on 2026-10-15.
Self-hosted through Astro's built-in local font provider; no runtime Google requests.
Only normal styles are included. Montserrat is variable; Poppins uses three static weights.
See the accompanying SIL Open Font License files.
